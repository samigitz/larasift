# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/samigitz/larasift/security/advisories/new).

Include the affected version, a clear description, reproduction steps, and the potential impact. Please do not open a public issue for an unpatched vulnerability.

You can expect an acknowledgement within seven days. Confirmed vulnerabilities will be investigated, fixed, and disclosed responsibly.

## Supported versions

Until LaraSift reaches version 1.0, only the latest tagged release receives security fixes.
