## [0.1.0] - 2026-09-16

### Added

- Standalone Composer binary for scanning the current Laravel project.
- Colour terminal output and versioned JSON output.
- Rule and category filters with configurable minimum severity.
- `LSEC-XSS-002` for dynamic, unescaped Blade output.
- Exact file, line, and column locations with remediation details.
